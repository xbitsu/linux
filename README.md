# Linux

## Installation
Download the latest [release](https://github.com/xbitsu/linux/releases/latest). Pick the package for your system.

### Debian, Ubuntu
```bash
sudo apt install ./xbit-amd64.deb
```
### Fedora, RHEL
```bash
sudo dnf install ./xbit-amd64.rpm
```
### Arch Linux
```bash
sudo pacman -U ./xbit-amd64.pkg.tar.zst
```
## Launch
Start xbit from the application menu, or run:
```bash
sudo xbit
```

The first VPN connection asks for the administrator password once.
